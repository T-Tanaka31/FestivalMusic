【操作方法】

左移動　　　→ Aキー
右移動　　　→ Dキー

ジャンプ　　→ SPACEキー
大ジャンプ　→ Wキー + SPACEキー
小ジャンプ　→ Sキー + SPACEキー

攻撃　　　　→ Jキー

ゲーム終了　→ Escapeキー
※Escapeキーを押すと、ゲーム中のどの画面からでもゲームを終了します。


【ゲームの流れ】

タイトル画面
　↓
Enterキーを押すとゲーム開始
　↓
ゲーム開始
　↓
1ステージのみで、ステージを進んでいく
　↓
ゲームクリア または ゲームオーバー
　↓
Enterキーを押すとタイトル画面に戻る


【ゲームのルール】

・敵に当たるとダメージを受ける
・攻撃を当てることで敵を倒すことができる
・HPが0になるとゲームオーバー
・ステージから落下するとゲームオーバー
・ステージを最後まで進むとゲームクリア
